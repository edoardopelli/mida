MIDA · Guida

Collegare Gmail e Classroom.

MIDA usa un client OAuth creato da te su Google Cloud. Il file JSON che Google genera viene importato nell'app, cifrato e salvato nel database: nessuna credenziale nel file .env.

Torna alle impostazioni

Prima di iniziare

Servono un account Google e pochi minuti nella console Google Cloud.

  • L'account Google usato per MIDA deve poter accedere a Gmail e Classroom della scuola.
  • Il progetto Google Cloud può essere nuovo o già esistente.
  • MIDA richiede solo permessi di lettura: non modifica email, corsi o file.

1. Crea il progetto e abilita le API

Tutto si fa da console.cloud.google.com.

  1. Apri la console e crea un progetto (o selezionane uno esistente) dal selettore in alto.
  2. Vai su API e servizi → Libreria e abilita: Google Classroom API Google Drive API Gmail API
  3. Vai su API e servizi → Schermata di consenso OAuth. Compila il nome dell'app e l'email di supporto. Se il progetto è in stato Testing, aggiungi il tuo account tra gli utenti di test.

2. Crea il client OAuth

Il client deve essere di tipo Applicazione web.

  1. Vai su API e servizi → Credenziali → Crea credenziali → ID client OAuth.
  2. Scegli Applicazione web come tipo di applicazione.
  3. In URI di reindirizzamento autorizzati aggiungi esattamente:
    {{ redirectUri }}
    Se cambi porta o dominio di MIDA, aggiorna qui l'URI e reimporta il JSON.
  4. Premi Crea e scarica il file JSON con il pulsante di download. Il file contiene client_id, client_secret e i redirect URI.

3. Importa il JSON in MIDA

Da qui in poi non serve più toccare la console, tranne per cambiare client.

  1. Apri Impostazioni → Account Google.
  2. Premi Importa JSON e seleziona il file scaricato da Google.
  3. MIDA verifica che il JSON contenga il redirect URI corretto, genera una chiave UUID, cifra il file con AES-256-GCM e lo salva nella collection googleClientCredentials.
  4. Premi Collega account Google, scegli l'account della scuola e autorizza i permessi di lettura.
Vai alle impostazioni

Permessi richiesti

Sono tutti in sola lettura e vengono mostrati da Google prima dell'autorizzazione.

  • Classroom — leggere corsi, compiti, materiali e annunci.
  • Drive (sola lettura) — scaricare gli allegati dei materiali Classroom.
  • Gmail (sola lettura) — cercare e archiviare le email della scuola.
  • Indirizzo email — mostrare quale account è collegato.

Sicurezza e dati

  • Il JSON del client e i token OAuth sono cifrati in AES-256-GCM. La chiave UUID è generata da MIDA e salvata accanto ai dati cifrati, mai in chiaro nel repository.
  • Rimuovi client elimina le credenziali e scollega l'account; email e materiali già scaricati restano in MIDA finché non li elimini.
  • Puoi revocare l'accesso in qualsiasi momento anche da myaccount.google.com → Sicurezza → App di terze parti.

Problemi comuni

Google mostra “redirect_uri_mismatch”
L'URI autorizzato non coincide. Deve essere identico a {{ redirectUri }}, compresi schema, porta e path.
MIDA rifiuta il JSON
Il file non contiene il redirect URI di MIDA. Aggiungilo al client OAuth, riscarica il JSON e reimportalo.
Google blocca l'accesso
Se il progetto è in stato Testing, aggiungi il tuo account tra gli utenti di test nella schermata di consenso OAuth.
L'account risulta da ricollegare
Il token è stato revocato o è scaduto. Premi Collega account Google nelle impostazioni per autorizzarlo di nuovo.
